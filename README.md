# tesla-navi — Phase 0 위치 검증 페이지

테슬라 차량 브라우저에서 Geolocation API가 어떻게 동작하는지 측정하는 단일 HTML 페이지(`index.html`).
위치 데이터는 브라우저 안(화면, localStorage)에만 남고 어디로도 전송되지 않습니다.

## 측정 모드
- **A 단독**: `watchPosition`만 실행
- **B 단독**: `getCurrentPosition`을 주기 호출 (응답을 받은 뒤 다음 요청 → 요청이 겹치지 않음)
- **A+B**: 비교용. 두 호출이 같은 위치 제공자를 공유할 수 있어 A의 결과가 B에 의해 부풀려질 수 있음

## 테스트 절차 (초안)
1. PC/폰에서 먼저 동작 확인
2. 정차(실외): A 단독 3분 → B 단독 3분
3. 주행: A 단독 10분 → B 단독 10분 (조작·관찰은 동승자, 운전자는 출발 전 시작만)
4. A+B 동시 비교
5. 각 측정 후 `정지` → 요약 화면을 폰으로 촬영

## 요약 화면 해석
- 정확도 중앙값 수~20m → GPS 수준 / 수백 m 이상 → Wi-Fi·IP 기반 의심
- speed·heading 값이 주행 중에도 계속 null → GPS가 아닐 가능성 높음
- 같은 timestamp 반복이 많음 → 캐시 재사용
- 갱신 간격 최대값이 크게 튐 → 연속 추적 끊김
- 권한 팝업이 다시 뜨는지는 페이지가 감지할 수 없으므로 직접 기록
