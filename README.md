# tesla-navi

테슬라 차량 브라우저에서 접속만으로 쓰는 카카오 기반 웹 내비 (개인·비상업용, 비용 0원).

- 내비 앱: https://aiboy2.github.io/tesla-navi/
- 위치 측정 페이지 (Phase 0): https://aiboy2.github.io/tesla-navi/phase0/

## 처음 쓸 때
1. 차량 브라우저에서 내비 앱 접속 → 위치 권한 허용
2. ⚙ 설정 → 카카오 REST API 키 입력 → 저장 (이 브라우저에만 저장, 저장소/서버로 보내지 않음)
3. 🔍 목적지 → 검색 → 결과 선택 → 안내 시작

## 위치 처리 원칙
현재 위치는 길찾기 출발지와 검색 기준점으로 **카카오에만** 전달됩니다. 별도 서버는 없습니다.

## 개발
- `npm install` 후 `npm test` (내비 계산 로직, 위치 전송 대상 정적 검사, 측정 페이지)
- 작업 절차는 `CLAUDE.md`의 "운영 절차", 진행 상황은 `PROGRESS.md`
